# AP STEM OS

This is an open-source, forever-free AP STEM (AP Calculus AB/BC, AP Physics 1, 2, C Mechanics and E&M, AP Statistics) score optimization site - not for learning everything deeply but instead designed for the express purpose of earning a 5. 

The "Practice" feature includes 1700+ questions modeled after real AP exam MCQs organized by unit and subtopic, tagged by difficulty (easy, medium, hard), along with concise explanations for the correct answer. Each question updates the "Score Command Center," which tells the user their subtopic strengths and weaknesses, respectively, based on a 70% threshold, in addition to unit mastery. It provides highest-ROI study suggestions based on weaknesses. After answering questions, users can head to the Answer Log in order to see how many questions they answered, and for incorrect answers, they can go the "Common Mistakes Database," search for their mistake, and then tag it for future reference. If their mistake does not match anything in the "Common Mistakes Database," they can add it by describing it to a built-in AI. The "Common Mistakes Database" features examples, "How to Avoid," and average point loss per mistake. In addition to the "Common Mistakes Database," another feature users can reference after answering a question incorrectly is the "Question Type Navigator," which is organized by unit and subtopic the exact same way as the "Practice" feature, and clicking on a feature card for that subtopic redirects the user to a page describing exactly how to answer both MCQs and FRQs on that subtopic correctly. The above describes the common workflow that gives this site its identity.

Supplemental resources include an "FRQ Library," "Topic Rundowns," a LaTeX-rendered "Formula and Strategy Guide," and an "Exam Strategy" guide. The FRQ library organized every FRQ from the past 26 years into categories of topics, based on each FRQ number, and redirects the user to that FRQ. "Topic Rundowns" feature a concise, exam-focused guide for every core concept essential to the AP exam for each unit. The LaTeX-rendered "Formula and Strategy Guide" features a 10-page, intuitive, easy-to-follow summary of all the formulas in the course needed for the AP exam and strategies you'll need to apply them correctly for the AP exam. It's intended as a last-minute review tool, a printable PDF for an AP student to have in their inventory. The "Exam Strategy Guide' features detailed calculator-usage tips accompanied by examples, detailed timing tips to earn the greatest number of points possible, and walkthroughs of how to efficiently approach certain types of questions.
